# Data

## `bmd.csv`

Bone mineral density (BMD, g/cm^2) measurements used in the empirical application.

Columns:

- `id`: observation index used in the manuscript and supplementary material.
- `t1`: BMD before the experimental study.
- `t2`: BMD after the experimental study.

Source: Johnson and Wichern, *Applied Multivariate Statistical Analysis*, Pearson, 1999. The same 24 paired observations are listed in the supplementary material.

The MIT license of this repository covers the software only. The data are included to make the empirical analysis reproducible; verify redistribution permissions before public release if your institution or publisher requires a separate data-license review.
